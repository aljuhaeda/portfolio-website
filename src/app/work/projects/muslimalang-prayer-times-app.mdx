## Overview

A Flutter mobile app providing prayer times and related Islamic utilities for users in Malang, Indonesia.

## What I fixed

The most severe bug in this project: the login screen, which is the app's entry point, was permanently unpassable — it blocked every single user from reaching any part of the app. I removed the broken gate and replaced two dead third-party API integrations that no longer worked.

## Redesign

After fixing functionality, I redesigned the UI with an emerald/gold color palette and an Islamic geometric pattern, arch-framed cards, and an automatic next-prayer highlight.

## Technologies Used

- **Flutter / Dart**
- Prayer-time calculation and scheduling

## Verification

Verified with a full Flutter SDK install — `flutter analyze` and `flutter test` clean, built for web, and clicked through the live app end to end.
