## Overview

A Multinomial Naïve Bayes classifier detecting hate speech against Islam in Indonesian-language tweets. The underlying research was published in the Journal of Informatics and Science Media (JISMEDIA), Vol. 1 No. 2, pp. 31–38, December 2024 (ISSN 3064-1942). The repository had been sitting in a buried folder with a README that overstated what the deployed model could actually do.

## What I fixed

- Promoted the project out of a nested folder into its own repo.
- Corrected a factually wrong README claim (an unverifiable "92%"-style headline number that didn't match the notebook).
- Reported per-class results instead of accuracy alone. In this dataset `Negatif` is hate speech against Islam (83.5% of 1,200 tweets) and `Positif` is non-hate (16.5%), so a model that calls almost every tweet hate still looks accurate.
- Re-audited the evaluation in November 2026 with a leak-free pipeline (vectorizer fit on training data only, alpha chosen without the test set): no configuration beats the always-predict-hate baseline (about 84%) on accuracy. The deployed config (alpha=2.0, 80/20 split), re-fit leak-free, scores **hate recall 0.9492 at precision 0.8500**, but **non-hate recall is 0.1316**: most non-hate tweets are classified as hate. The published figures and the audit are both documented in the repository.
