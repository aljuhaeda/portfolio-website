## Overview

A sentiment/hate-speech classifier for Indonesian Twitter comments. The underlying research was published in JISMAN Journal (Nov 2024). The repository had been sitting in a buried folder with a README that overstated what the deployed model could actually do.

## What I fixed

- Promoted the project out of a nested folder into its own repo.
- Corrected a factually wrong README claim.
- Swapped the deployed model for one with real hate-speech recall — **32%** recall on the hate-speech class versus **14%** for the previously deployed model.

## Technologies Used

- **Python**, **scikit-learn** — Naïve Bayes classifier
- **NLP** preprocessing for social media text
- **Streamlit** — deployed demo
